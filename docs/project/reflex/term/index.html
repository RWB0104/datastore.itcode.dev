개인정보처리방침

최종 수정일: 2026-07-24 (KST)

Reflex는 Flex.team을 더 편하게 사용하기 위해 만들어진 비공식(Unofficial) 브라우저 확장 프로그램입니다. Reflex는 플렉스팀 주식회사와 아무런 제휴·협력 관계가 없습니다.

수집(접근)하는 정보

  • Flex.team 로그인 쿠키(AID, V2_WS_AID) — 사용자를 대신해 Flex.team API를 호출할 때 인증 용도로만 사용됩니다.
  • Flex.team 프로필 정보(이름, 이메일, 전화번호, 부서, 프로필 사진) 및 근무 관련 정보(근태 기록, 연차 잔여일수) — 확장 프로그램 화면에 표시하기 위해서만 조회합니다.

정보 사용 방식

위 정보는 오직 확장 프로그램 화면(대시보드, 캘린더, 설정)을 보여주기 위해서만 사용되며, 모든 처리는 사용자의 브라우저 안에서만 이루어집니다.

하지 않는 것

  • 자체 서버를 운영하지 않습니다. Reflex는 사용자의 데이터를 수신·저장·기록하는 어떤 인프라도 가지고 있지 않습니다.
  • 어떤 정보도 제3자에게 판매, 공유, 전송하지 않습니다.
  • 분석/트래킹/광고 도구를 사용하지 않습니다.

로컬 저장 정보

Reflex가 기기에 저장하는 유일한 정보는 무작위로 생성된 기기 식별자이며, API 요청 식별 용도로만 쓰입니다. 이 값은 Flex.team 외에는 어디로도 전송되지 않으며, 확장 프로그램을 삭제하면 함께 삭제됩니다.

데이터 보관

Reflex가 통제하는 어떤 시스템에도 데이터가 경유하거나 저장되지 않으므로, 보관하는 데이터가 없습니다.

Privacy Policy

Last updated: 2026-07-24 (KST)

Reflex is an independent, unofficial browser extension that provides a streamlined interface for Flex.team. Reflex is not affiliated with, endorsed by, or connected to FlexTeam Inc.

What data we access

  • Your Flex.team authentication cookies (AID, V2_WS_AID), used only to authenticate requests made on your behalf directly to Flex.team's own API.
  • Your Flex.team profile information (name, email, phone number, department, profile photo) and work-related data (attendance records, annual leave balance), retrieved to display within the extension's UI.

How we use this data

This data is used exclusively to render the extension's interface (dashboard, calendar, settings) for you. It is processed entirely within your browser.

What we do not do

  • We do not operate any backend server. Reflex has no infrastructure of its own that receives, stores, or logs your data.
  • We do not sell, share, or transmit your data to any third party.
  • We do not use analytics, tracking, or advertising services.

Local storage

The only data Reflex stores locally on your device is a randomly generated device identifier, used to tag API requests. This is never transmitted anywhere except to Flex.team itself, and is removed when you uninstall the extension.

Data retention

We retain no data, because none passes through or is stored on any system we control.
